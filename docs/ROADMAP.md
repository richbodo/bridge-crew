# Roadmap

Goals for later, each waiting for its own plan or issue. What's being built now is in
[`docs/plans/`](plans/).

## Game Studio

From [Bigger games](plans/bigger-games-2026-11-16.md) (issue #9):

- **A Tune panel.** Sliders for the numbers in a game's `CONFIG` block, such as gravity or
  speed, so a student can change one and see what happens, with no model call. The teacher's
  bigger games all keep their numbers in `CONFIG`, which suits it.
- **More libraries on the shelf**, one at a time, when a game needs one: physics engines
  (matter.js for 2D, cannon-es for 3D), the Phaser 2D engine, and Tone.js for sound.
- **Hosting games online**, so a family gets a link as well as a file. Now planned: play links
  on GitHub Pages, in [Games on GitHub](plans/games-on-github-2026-11-16.md).
- **Multiplayer games.**
- **Video in games**, such as a trailer on a title screen.
- **Image-generation services**, for pictures beyond what can be drawn as code. This needs a
  second AI provider, so it needs its own decision on cost, privacy and safety for students.
